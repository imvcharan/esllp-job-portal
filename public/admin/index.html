Razorpay settings

Configure the payment gateway used for candidate purchases and employer subscriptions.

Credentials are encrypted before being stored. API and webhook secrets are write-only and never returned to the browser. The encryption key must remain stable and be backed up securely; losing or changing it makes saved secrets unreadable. Do not enter live credentials until your HTTPS domain and both webhooks are ready.

Employer subscription plans

Plan IDs must refer to monthly INR plans in the same Razorpay account as the API key.

Webhook endpoints

Configure these HTTPS endpoints in Razorpay and select the listed events:

Employer subscriptions: /api/billing/razorpay/webhook — subscription.activated, subscription.charged, subscription.resumed, subscription.halted, subscription.cancelled, subscription.completed.

Candidate one-time payments: /api/billing/razorpay/candidate-webhook — payment.captured.

Use the same webhook signing secret for both endpoints. Updating it here takes effect immediately; update the secret in Razorpay at the same time.

Superadmin controls

Platform controls

Manage registration and moderation gates. Defaults preserve the current approval-first workflow.

Changes are saved to the database and audited. Disabling an approval requirement affects new access or publication requests; it does not retroactively approve pending employers or jobs. Rejected employers remain blocked. Restore defaults resets registration, approval, taxonomy, application-stage, and report settings.

Registration and moderation

Loading settings…

Job taxonomies and search suggestions

Edit one option per line. Categories and industries are stored on new or edited jobs; employment and workplace values are validated across job posts and candidate preferences. Location values are suggestions only, so employers may still enter a new location.

Applicant tracking stages

Edit one stage per line as key|label|next-stage-key,next-stage-key. Keys use lowercase letters, numbers, and underscores (maximum 20 characters). Keep the four built-in keys submitted, in_review, interview, and rejected. Add custom stages as needed; a custom stage cannot be removed while an application is currently in it. Rejected is terminal.

Analytics report definitions

Edit one supported report per line as key|label|enabled. Use enabled or disabled, and reorder lines to reorder reports. Remove a line to hide that report. Keys are fixed to metrics currently supported by the platform; custom SQL is not accepted.

Other admin-managed configuration

Pricing and employer entitlements are in Razorpay settings; candidate service prices and availability are in Candidate services. Public pages, FAQs, blog posts, announcements and SEO fields are managed in Website content.
